Installation Instructions

  1. Tap Download APK above.

    Settings → Apps → [Your Browser] → Install unknown apps → Allow
  3. Open the downloaded .apk file and tap Install.
  4. Open the app – your admin may send you a provisioning link that pre-fills the server details automatically.
